# Nomi project-page screenshots

Production-ready, unaltered screenshots captured from the Nomi renderer at
1440 × 1100 px. These are real UI captures, not generated interface mockups.

## Files

Each view is supplied in both formats:

- `projects-overview-dark.webp` / `.png` — Projects collection, dark theme.
- `projects-overview-light.webp` / `.png` — Projects collection, light theme.
- `project-detail-dark.webp` / `.png` — Release notes project detail, dark theme.
- `project-detail-light.webp` / `.png` — Release notes project detail, light theme.

Use WebP for web delivery; use PNG where lossless pixels are required. WebP
files are optimized, metadata-stripped exports; PNG files are original
lossless captures. Both formats retain the 1440 × 1100 dimensions.

## Capture details

- Captured from the existing Nomi app renderer using headless Chromium at
  1440 × 1100 CSS pixels, device scale factor 1.
- Dark and light color schemes; reduced motion enabled.
- Web fonts were stubbed to avoid network-dependent font loading.
- No screenshots, scripts, or other files were added to the Nomi repository.
