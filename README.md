# HyperColorSignal GitHub organization profile

This repository contains the public organization profile shown at [github.com/hypercolorsignal](https://github.com/hypercolorsignal). Its source is [`profile/README.md`](profile/README.md).

The public assets are organized under [`assets/hcs/`](assets/hcs/), [`assets/neo./`](assets/neo./), and [`assets/nomi./`](assets/nomi./). HCS brand guidance is in [`assets/hcs/brand.md`](assets/hcs/brand.md); Nomi screenshots are in [`assets/nomi./screenshots/`](assets/nomi./screenshots/). Editable brand sources and the Astro website are maintained separately from this public asset repository.
